Layout optimization (Optimize button)

        

          An Optimize run charges 1 token for the composer/packer pass (the first look at the PDF), then charges
          each AI loop separately based on what that loop actually cost us to run. A run that settles after 2 loops
          costs less than one that uses all 5.
          


          How the per-loop charge works. Every AI call reports exactly how much text went in and came back.
          We turn that into a dollar cost at current Anthropic rates, then divide by the figure below and round up,
          with a minimum of 1 token per loop. So if a loop costs us 12 cents and this is set to 8, the user is charged 2 tokens.
          


          Raising this number makes Optimize cheaper for users; lowering it makes it dearer. It is read live at the
          moment of charging, so a change takes effect on the very next run with no deploy. Minimum 1 cent (0 is not allowed
          because the charge divides by it). Magazine books cost roughly twice Picture Book ones because they genuinely send
          about twice as much text per page.

Genre
